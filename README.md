# Laporan Kegiatan Harian

Aplikasi web sederhana untuk manajemen laporan kegiatan harian, dibangun dengan HTML, CSS, dan JavaScript murni. Dapat diakses online melalui GitHub Pages dan dikembangkan secara open source.

## Fitur

- Tambah laporan kegiatan harian (tanggal, kegiatan, deskripsi, status)
- Daftar laporan diurutkan dari yang terbaru
- Ubah status: Selesai, Proses, Tertunda
- Hapus laporan
- Data tersimpan di browser (localStorage)
- Responsif untuk layar kecil

## Teknologi

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages (hosting gratis)

## Cara Menjalankan Secara Lokal

1. Clone repositori ini:

   ```bash
   git clone https://github.com/USERNAME/laporan-kegiatan-harian.git
   cd laporan-kegiatan-harian
   ```

2. Buka `index.html` di browser favorit kamu.

## Deploy ke GitHub Pages

1. Push kode ke repositori GitHub.
2. Masuk ke **Settings > Pages** di repositori.
3. Pilih branch `main` (atau `master`) dan folder `/ (root)`.
4. Klik **Save**.
5. Situs akan online di `https://USERNAME.github.io/laporan-kegiatan-harian/`.
